## ⚡ The Problem & The Solution

Every semester, students miss important hackathons, college events, and exam submission deadlines because announcements are scattered across dozens of unread WhatsApp groups. 

**Vanko solves this in one tap:**
1. **Share any WhatsApp message** (or event poster) directly to Vanko.
2. **AI Schedule Parser** extracts event titles, dates, timings, venues, and registration links in under 400 milliseconds.
3. **Structured Calendar Sync**: Automatically lands on your personal calendar with native alarms that work 100% offline.

---

## ✨ Key Features

* **⚡ Instant AI Notice Extraction:** One-tap Android Share Sheet integration to parse raw notice texts into structured event cards.
* **📴 100% Offline-First Architecture:** Local storage and native Android exact alarms ensure reminders trigger reliably without internet or cellular connectivity.
* **🏫 Campus Community Feeds:** Centralized verified event hub for campus clubs, hackathons, workshops, and student activities.
* **🔒 Privacy-Centric & DPDP Compliant:** Zero advertisements, no third-party trackers, zero data selling, and one-tap in-app account deletion.

## 🛠️ Architecture & Tech Stack

* **Mobile Client:** React Native, Expo SDK 54, TypeScript, React Navigation
* **Backend:** Cloudflare Workers (Edge Serverless), Jose (JWT Verification)
* **Database & Auth:** Firebase Auth, Google Cloud Firestore, Firebase Cloud Messaging (FCM)
* **AI Engine:** Groq Cloud Llama-3 Models with multi-key failover and cooldown balancing
* **Web & SEO:** Semantic HTML5, Vanilla CSS, JSON-LD Structured Data, Vercel Edge Network
